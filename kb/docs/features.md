# GaplessPaste 功能与行为规则

写给想知道「app 现在能做什么、每个功能按什么规则运作」的人。这里只描述当前状态；最初的需求和决策过程见 [v1 spec](../plans/2026-07-06-gapless-paste-v1-spec.md)（其中菜单结构、ControlPath 位置、同步剪贴板的形态已与现状不同，以本文为准），历次改动见 `kb/sessions/`。预览远端目录窗口单独成文：[preview-window.md](preview-window.md)。

## 核心思路：按内容类型走两条回传通道

材料传到远端之后，远端的 Claude Code 怎么拿到它，取决于内容类型：

| 本机剪贴板内容 | 动作 | 回传通道 | 在远端怎么用 |
| --- | --- | --- | --- |
| 文件引用（Finder ⌘C） | 按原名上传到目标目录 | 远端绝对路径写入**本地**剪贴板 | 终端里 ⌘V 把路径粘给 Claude Code |
| 图像数据（截图、浏览器拷图） | 重命名后上传到目标目录 | 图像本体注入**远端**剪贴板 | Claude Code 里 Ctrl+V 吸入图片 |
| 图像 / 文本（剪贴板同步） | 不进目录，直通远端剪贴板 | 内容本体注入**远端**剪贴板 | 同上 |

文本粘进终端会变成键入流传到远端，所以路径走本地剪贴板就够了；图像走不了键入流，只能反向注入远端剪贴板。

## 菜单结构

- 顶部：两行传输摘要、「查看传输详情…／查看失败详情…」、「拷贝上次上传的远端路径」、可重试失败后出现的「重试上次操作」
- 每台机器一个分区，依次是：「同步到远端剪贴板 →」「从远端剪贴板同步 ←」「🔍 预览远端目录…」「⚡ 快速上传」（机器配了默认目录才出现）、各个「📁 目录」
- 底部：「设置…」（⌘,）、「重载配置」、「打开日志」、「检查更新…」、「退出」

有操作在进行时，上传和同步类菜单项置灰；预览不受影响。

## 传输摘要与菜单栏反馈

菜单正常宽度为 288 pt。摘要第一行显示结果，第二行显示内容类型／文件数、方向与相对时间，两行文字左对齐。长机器名按实际可用宽度省略；文件名和错误正文进入详情，不撑宽摘要。摘要不可点击，鼠标经过不高亮。尚无记录时显示「还没有传输记录」及开始指引。

菜单关闭时，主图标右下角仍即时显示状态：发送用纯 ↑、接收用纯 ↓，均无托盘；成功用 ✓，失败或部分成功用 !。进行中超过 300 ms 才轻微改变徽标透明度，主图标不动；系统开启减少动态效果时箭头保持静态。成功约 2 秒后恢复待机，记录继续保留；过期回调不会清除新操作的反馈。

只打开菜单不解除失败提醒，打开对应失败详情或开始新操作才解除；失败记录与合法重试入口保留。取消重命名、空剪贴板、空远端或平台拒绝不产生成功记录，也不残留进行中徽标。

详情窗口显示该次记录的稳定快照：完整文件名、多文件列表、方向、目录、类型、可用的大小／字符数、起止时间、远端路径和失败原因。文字可选择、换行和滚动；新传输不会覆盖已打开的详情。没有源文件名的图像／文本不虚构名称，不展示剪贴板文本正文。最近记录只存在内存中，重启后清空。

## 目录上传

点击某个目录后按剪贴板内容分类处理：

- **文件引用**：按原文件名上传，支持多文件。完成后把远端绝对路径写入本地剪贴板，多个路径换行分隔
- **图像数据**：先弹重命名浮窗（预填默认名、选中主文件名部分，扩展名锁定 `.png`），回车上传、Esc 取消。上传成功后把图像注入远端剪贴板，本地剪贴板保持不动
- **空或不支持的内容**：通知提示没有可上传的内容

命名规则：

- 图像默认名是 `shot-YYYYMMDD-HHmmss.png`（本地时间）
- 文件名里的 `/`、`:`、控制字符、空白统一替换为 `-`，避免远端路径带空格给引用添乱
- 重名时在扩展名之前追加 `-1`、`-2`……直到不冲突，文件引用和图像都适用

回传的路径一律是绝对路径，因为 Claude Code 不一定展开 `~`。为此首次操作某台机器时会探测一次它的 `$HOME` 和系统类型，结果持久缓存；「重载配置」或在设置里保存都会清掉这份缓存。

失败时通知里带错误摘要（远端 stderr 首行），并可从菜单重试。

图像文件已上传，但后续远端剪贴板注入失败（包括非零退出码与抛出异常）时，显示「已上传，剪贴板写入失败」，保留已上传的远端路径及失败原因。为避免生成重复文件，此类部分成功不提供重新上传；可用「拷贝上次上传的远端路径」继续使用文件。

## 快速上传

目录可以标记为某类内容的默认落点（文件或图像）。「⚡ 快速上传」按剪贴板类型直接传到对应的默认目录，省掉选目录这一步，其余行为与目录上传完全一致（图像仍弹重命名浮窗）。每台机器每类至多一个默认目录。

## 拖拽上传

把文件拖到菜单栏图标上，图标下方弹出面板，所有「机器 × 目录」平铺成行，每行是独立的投放目标；松手后按文件引用的方式上传。只接受文件拖拽，浏览器里直接拖出的图像数据不支持。

## 剪贴板同步（双向）

不经过目录，名字无意义，所以没有重命名浮窗。

**推送到远端**（「同步到远端剪贴板 →」）：

- 图像数据：传到远端一个固定的临时文件（`~/.cache/gapless-paste/clipboard.png`，每次覆盖、不累积），再注入远端剪贴板
- 纯文本：直接注入
- 单个图片文件引用（Finder 里 ⌘C 的 png / jpg / heic / webp 等）：读出文件转成 PNG，按图像数据处理
- 多个文件或非图片文件：拒绝，提示改用目录上传

**从远端拉取**（「从远端剪贴板同步 ←」）：优先取图像，远端剪贴板里不是图像就取文本，文本也为空则提示远端剪贴板为空。图像以 PNG 和 TIFF 两种格式写回本地剪贴板，保证各类 app 都能粘贴。

## 远端不是 macOS 时

剪贴板注入只实现了 macOS 远端。对其他系统：

- 两个同步菜单项置灰。尚未探测过的机器先保持可用，点击时探测，发现不是 macOS 就提示并在下次打开菜单时置灰
- 目录上传图像时自动降级：远端路径以文本写回本地剪贴板，通知注明已拷贝路径

另一个前提：SSH 登录的用户必须和远端已登录图形会话的用户是同一个，否则写不进那个会话的剪贴板。

## 传输层

直接调用系统的 `ssh` 和 `scp`，不内嵌 SSH 库。这样 `~/.ssh/config` 里的别名、密钥、agent、跳板全部天然可用，配置里只需写别名。

所有连接通过 ControlMaster 复用（保持 10 分钟），首次连接后的重复操作是毫秒级的，适合连续截图连续上传。复用连接的 socket 放在 `/tmp/gaplesspaste-<uid>/`：unix socket 路径有长度上限，放进 Caches 或 Application Support 会超限。macOS 会周期清理 `/tmp`，所以每次执行命令前都会确认这个目录存在。

## 配置与设置窗口

配置保存在 `~/Library/Application Support/GaplessPaste/config.json`，内容是机器列表，每台机器有名称、SSH 别名和一组远端目录。

日常通过「设置…」窗口编辑：改动即时校验，合法的改动停手半秒后自动保存并生效，没有保存按钮；不合法时暂不保存，就地显示原因。首次启动会写入一份示例配置并直接打开设置窗口。

设置窗口保存时整体重写配置文件，手写进去的未知字段（如 `_readme`）会丢失，这是预期行为。手改文件后用「重载配置」生效。

## Dock 形态

平时是纯菜单栏 app，没有 Dock 图标。预览、设置或传输详情窗口开着的时候，app 临时变成普通 app：出现 Dock 图标和主菜单栏，可以 ⌘Tab 切到它、⌘` 在它的窗口之间切换；最后一个普通窗口关闭后退回 accessory，Dock 图标消失。仅打开状态栏菜单不会出现在 Dock。窗口全部最小化时仍属于有窗口，点 Dock 图标会恢复最近用过的那个。重命名浮窗、拖拽面板这类临时浮窗不触发这个切换。

## 应用内更新

从 v0.2.0 起使用 Sparkle 2。正式版默认每天检查一次稳定版更新；发现更新后显示标准对话框，用户确认安装后替换 app 并重启，不允许静默安装。菜单「检查更新…」可立即手动检查，检查或安装进行中按 Sparkle 的 `canCheckForUpdates` 置灰。更新说明在对话框内显示，完整变更记录链接到 GitHub Release。

Debug 构建只允许手动检查，后台检查由 delegate 拒绝，不覆盖与正式版共用的用户偏好。0.2.0 之前的版本没有 Sparkle，需通过 dmg 或 Homebrew 升级一次。

更新源是本仓库最新 Release 的 `appcast.xml`；下载使用固定版本的已公证 dmg，并验证 EdDSA 签名。Homebrew cask 标记 `auto_updates true`，日常更新交给应用内流程。
