# 预览远端目录窗口

写给想知道「预览窗口能做什么、各项操作按什么规则运作」的人。只描述当前状态；其余功能见 [features.md](features.md)，已知缺陷见 `kb/known-issues.md`。

## 它解决什么问题

材料传到远端之后，或者远端的 Claude Code 生成了图片、日志、音频之后，不用另开终端或 Finder 挂载就能看到远端目录里的内容，并把需要的文件拿回本机。

## 打开

每台机器的菜单里有「🔍 预览远端目录…」。点击后弹出路径输入框，下方列出这台机器最近打开过的路径（每台机器记 8 条），点一下即填入。确认后打开一个独立窗口；窗口可以开多个，彼此互不影响。

输入的路径会先规范化：去掉末尾的 `/`，连续的 `/` 折叠成一个。

## 布局

左侧是目录树，右侧是文件预览。中间的分割条可以拖动，侧栏宽度只跟随拖动变化，不会因为右侧内容变化而跳动。

顶栏从左到右：当前根路径、向上按钮、（选中两张以上图片时出现的）连接 Zoom / 连接 Scroll、刷新、置顶。置顶后窗口浮在其他窗口之上。

## 目录树与导航

- 子目录在展开时才去远端列出内容，列过的目录不会重复请求
- **向上**（顶栏「↑」或 ⌘↑）：把树根切到上一级。原来的根作为展开状态的子节点留在新树里，已选中的文件和右侧预览都保留
- **进入**（双击目录行）：把树根切到该目录。选中的文件里只保留位于新根之下的
- 已经列过的目录，进出都不会再发请求
- 根是 `/` 时不能再向上
- **刷新**（顶栏）：重新列出当前根下的目录树。它不清磁盘上的文件缓存
- 窗口标题跟随当前根路径

## 能预览什么

| 类型 | 判定 | 表现 |
| --- | --- | --- |
| 图像 | png / jpg / gif / bmp / tiff / heic / webp 等 | 渲染图片，可缩放 |
| 音频 | wav / mp3 / m4a / aac / flac / aiff / caf | 播放 / 暂停、可拖动的进度条、当前时间与总时长 |
| 文本 | 其余所有文件都先当文本尝试 | 显示内容，超过 512 KB 只显示开头部分并注明 |
| 二进制 | 无法按 UTF-8 解码的文件 | 不预览，但仍可复制和下载 |

ogg / opus 系统解码器不支持，不作为音频处理。切到别的文件时，正在播放的音频自动停止。

## 多文件对比

按住 ⌘ 点选多个文件，右侧分成多栏并排显示。选中两张以上图片时，顶栏出现两个开关：

- **连接 Zoom**：各栏的缩放比例保持一致
- **连接 Scroll**：各栏的滚动位置保持一致，按位置比例对齐，所以尺寸不同的图片也能对上同一区域

## 图像缩放

图片默认以「适应窗口」方式显示：缩小到能完整放下，但不会放大超过原始尺寸。每栏标题栏的按钮组提供缩小、放大、当前百分比（点击回到 100%）、回到适应窗口；触控板双指捏合同样可以缩放。缩放范围 10% 到 800%。

## 把文件拿回本机

- **复制**：⌘C 或 ⌃C（或每栏的复制按钮）把选中的文件作为文件引用放进剪贴板，可以直接粘贴到 Finder 或其他 app
- **下载**：每栏的下载按钮弹出另存对话框。不能预览的二进制文件同样可以下载

导出的文件保留远端的原始文件名。

## 文件缓存

预览过的文件缓存在 `~/Library/Caches/GaplessPaste/preview/`，所有窗口共用，关窗、重启 app 都不会清掉。再次打开同一台机器上同一路径的文件时直接用缓存，不再下载。

缓存按「机器 + 远端完整路径」定位：路径经过散列，所以不同目录下的同名文件不会冲突；最后一段保留原始文件名，所以导出时名字是对的。

缓存不会自动发现远端文件的变化。远端文件更新后，用每栏标题栏的刷新按钮强制重新下载；多个窗口同时刷新同一个文件是安全的。
