# 发布 v0.3.0，并验收签名公证、Sparkle feed 和 Homebrew 安装

## 概要

按用户的 new minor 请求，从最新正式版 v0.2.0 升至 v0.3.0。当前 master 的 4 个未推送提交与 annotated tag 一起原子推送，发布源码为 `e43c50d7d693f526fde6c1477d7b88a78247c01f`，未改版本占位或应用代码。新版包含两行传输摘要、详情窗口、状态徽标、288 pt 菜单、Dock 最后窗口收尾修复，以及图像上传后的部分成功处理。

[Release](https://github.com/reorx/gapless-paste/releases/tag/v0.3.0) 已公开，构建号为 7。[CI run 39437781089](https://github.com/reorx/gapless-paste/actions/runs/39437781089) 第二次执行的 release 和 homebrew job 均成功；tap 提交为 `b5150b1`（`github-actions[bot]`，`gapless-paste 0.3.0`）。Release 正文补充了面向用户的变更摘要和升级说明，已发布的三个附件未替换。

## 修改的文件

- `AGENTS.md`：发布文档索引增加产物验收，并明确已发布 tag 和产物不可重写。
- `kb/docs/release.md`：更新示例版本、skill 路径、Homebrew `--greedy` 升级说明、分发验收和网络失败的重跑方式；保留自动检查的真实验收边界。
- `kb/next-up.md`：删除已完成的 tap／默认升级行为检查，仅保留真实每日自动检查与确认安装。
- 本会话记录：归档本次发布和验收结果。验证脚本、日志与下载附件留在忽略的 `tmp/2026-10-20-release-v0.3.0/`。
